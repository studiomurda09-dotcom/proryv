Стратегии

Методы обхода. Посмотрите, как стратегия режет пакет: введите сайт и выберите стратегию.

Автоподбор

Главная фишка: программа сама находит дыру в DPI вашего провайдера и чинит обход, когда провайдер что-то меняет.

Подобрать стратегиюПеребирает методы и проверяет сайты напрямую, мимо VPN. Лучшая стратегия сохранится сама. 1–3 минуты.
Самолечение и сторожProryv следит за соединениями и раз в 5 минут сам проверяет сайты включённых пресетов. Если сайт перестал открываться — переподберёт стратегию (не чаще раза в 15 минут) и пришлёт уведомление.
Случайные фейкиКаждый фейк со случайным именем сайта и разрезом — DPI не сможет поймать их по шаблону.

Списки

По одному адресу на строку. Поддомены включаются автоматически. Изменения сохраняются сами.

Свои домены0
Работают, когда включён пресет «Свои домены». Автоподбор ищет один обход, который открывает их все.
Исключения0
Эти сайты никогда не обрабатываются. Банки, Госуслуги, Яндекс, VK, маркетплейсы и игры с античитом (~150 доменов) уже исключены встроенным списком — сюда добавляйте свои.
Game FilterОбход для игр: фейки перед первыми пакетами соединения к игровым серверам (порты 1024–65535). Как одноимённый режим в zapret.
Игровые серверы (диапазоны IP)0
По одному на строку, формат 128.116.0.0/17 или 2620:2b::/40. По умолчанию — серверы Roblox. Game Filter действует только на эти адреса, чтобы не трогать остальной трафик.

Диагностика

Почему сайт не открывается: подмена DNS, блокировка по IP или DPI.

Скорость видео и музыкиКак сейчас грузятся видео YouTube и музыка SoundCloud через обход. Скорость видео сравнивается со скоростью вашего канала.
Поделиться рабочими стратегиямиОтправьте в общую базу, какие стратегии работают у вашего провайдера, — новые пользователи с ним получат их сразу.
Отчёт для помощиВерсия, провайдер, стратегии, ошибки и какие сайты не открываются — без IP и ваших доменов. Скопируйте и отправьте в Discord.

Шпаргалка по параметрам
--dpi-desync=fake, multisplit, multidisorder, split, disorder, fakedsplit, fakeddisorder, hostfakesplit — через запятую --dpi-desync-split-pos=где резать: 1, host, endhost, midsld, sniext+1 (и midhost — только в Proryv) --dpi-desync-split-seqovl=наложение: сколько байт фейка подложить перед данными --dpi-desync-split-seqovl-pattern=файл tls_clienthello_САЙТ.bin — к какому сайту фейк наложения --dpi-desync=fakedsplitразрез + фейк той же длины вокруг каждого куска (fakeddisorder — куски задом наперёд) --dpi-desync=hostfakesplitимя сайта отдельным куском, вокруг — фейки с выдуманным именем --dpi-desync-autottl=TTL фейков по числу хопов до сервера: -1:3-20 (поправка:мин-макс) --dpi-desync-fooling=как обмануть сервер: ts, badseq, badsum, md5sig, datanoack --dpi-desync-ttl=малый TTL фейка: пакет умрёт по дороге после DPI --dpi-desync-repeats=сколько раз отправить фейк --dpi-desync-fake-tls=файл tls_clienthello_САЙТ.bin — какой сайт в фейке
