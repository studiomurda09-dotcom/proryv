# Шаблон: новая версия в Discord

Замени `X.Y.Z` и списки. Пункты пиши человеческим языком: что стало лучше для пользователя, а не что поменялось в коде.

```
# 🚀 Proryv vX.Y.Z

## ✨ Новое
- …

## 🛠 Исправлено
- …

## ⬇️ Обновиться
**Уже стоит Proryv** — программа сама предложит обновиться, жми «Обновить» на главной.
**Впервые** — качай `Proryv_X.Y.Z_x64-setup.exe`:
https://github.com/studiomurda09-dotcom/proryv/releases/tag/vX.Y.Z

Что-то сломалось после обновления — пиши сюда, приложи название провайдера и что не открывается.
```

## Пример (0.2.2)

```
# 🚀 Proryv v0.2.2

## ✨ Новое
- Автоподбор стал в несколько раз быстрее — сайты проверяются одновременно
- База стратегий с GitHub теперь проверяется перед применением

## 🛠 Исправлено
- Сайты иногда «подвисали» на полсекунды при открытии — больше нет
- Меньше потерь пакетов при большой нагрузке на сеть
- Убрана стратегия «Медленный разрез»: она тормозила весь трафик

## ⬇️ Обновиться
**Уже стоит Proryv** — программа сама предложит обновиться, жми «Обновить» на главной.
**Впервые** — качай `Proryv_0.2.2_x64-setup.exe`:
https://github.com/studiomurda09-dotcom/proryv/releases/tag/v0.2.2

Что-то сломалось после обновления — пиши сюда, приложи название провайдера и что не открывается.
```
