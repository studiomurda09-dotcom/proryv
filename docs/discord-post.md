# 🛡️ Proryv — YouTube, Discord и Telegram без VPN

Бесплатная программа для Windows, которая обходит блокировки провайдера. Трафик идёт напрямую, поэтому скорость не падает и VPN не нужен.

## ⚡ Что умеет
- **Автоподбор.** Сам находит способ обхода под **твоего** провайдера за 1–3 минуты
- **Самолечение.** Провайдер что-то поменял — Proryv сам переподберёт стратегию
- **Discord с голосом.** Голосовые каналы работают без VPN
- **Telegram.** Встроенный прокси, подключается одной кнопкой
- **Roblox и другие игры.** Game Filter (TCP / UDP)
- **Не ломает VPN, банки и Госуслуги.** Их Proryv не трогает
- **Обновляется сам** — в один клик внутри программы
- Русский и English, поиск по настройкам (Ctrl+F)

1. Установи и разреши права администратора

3. «Автоподбор» → «Подобрать» → большая кнопка на главной

# 🛡️ Proryv — YouTube, Discord and Telegram without a VPN

A free Windows app that bypasses internet provider blocks. Traffic goes directly, so there is no speed loss and no VPN needed.

## ⚡ Features
- **Auto-tune.** Finds a bypass method for **your** provider in 1–3 minutes
- **Self-healing.** Provider changed something? Proryv re-tunes the strategy by itself
- **Discord with voice.** Voice channels work without a VPN
- **Telegram.** Built-in proxy, connects in one click
- **Roblox and other games.** Game Filter (TCP / UDP)
- **Safe for VPNs, banks and government sites.** Proryv leaves them alone
- **Updates itself** — one click inside the app
- Russian and English, settings search (Ctrl+F)

## ⬇️ Download
**https://github.com/studiomurda09-dotcom/proryv/releases/latest**
Get the `Proryv_…_x64-setup.exe` file.

## 🚀 How to start
1. Install it and allow administrator rights
2. Windows Defender warns about the WinDivert driver? That's normal, it does the same for zapret: “More info” → “Run anyway”
3. “Auto-tune” → “Find” → the big button on Home
4. Done ✅

⚠️ Don't run it together with zapret / GoodbyeDPI — they will interfere with each other.
